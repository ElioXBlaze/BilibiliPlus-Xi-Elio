# BilibiliPlus Xi/Elio · 哔哩哔哩 iPad 增强套件

面向 **iPad Pro / iPadOS Safari + Stay** 的单文件用户脚本，只用一个脚本就把移动版哔哩哔哩网页上那些别扭的地方补齐：搜索、播放、倍速、全屏、屏蔽、截帧、直链，全部收进一个 Shadow DOM 面板里，不和其他脚本打架。

> 当前版本：**2.0.2**　作者：Xi/Elio X. Blaze

---

## 它解决什么问题

iPad 上看 B 站网页版，常年会遇到几件事：

- 顶栏搜索框在播放页会收起来，点不到，只能被迫回首页；
- 视频不会自动播，每次都要手动点一下，还要再点一次解除静音；
- 倍速选项有限，看完一节网课切回去又要重设；
- 「全屏」在 Safari 上不能真正铺满，边缘总有黑边；
- 推荐流里推过来不想看的区和 UP 主，只能一条条点「不感兴趣」；
- 想存一个画面、想拿一条能离线放的直链，网页版没有入口。

这个脚本把这些都做成了可开关的能力，并且为 iOS 做了大量兼容降级。

## 功能一览

**搜索**

- 零导航页内搜索：不用回首页，当前页面直接叫出搜索
- 浮层搜索：原生风格的面板，带联想词与分类结果
- 原生面板搜索与「再按一次复原」开关
- 三条诊断命令：搜索面板没弹出、浮层联想通道、原生顶栏收起，都能一键复制诊断

**播放器**

- 官方接口三连：无币时自动补赞藏（走官方接口，不刷量）
- 进播放页自动起播：静音起播 + 首次手势恢复音量 + 官方播放按钮兜底
- 倍速：档位记忆、长按 3×、一键回 1×（清档位记忆）、1×/2× 快切
- 弹幕显示开关：按**真实状态载体**校验，不是只看按钮样式；发弹幕完全交还 B 站官方输入框，不劫持 `A` / `Shift+Enter`
- 音量记忆与「立即解除静音」，附音量诊断（记忆值 / 系统音量边界）
- 起播诊断：一条命令告诉你「为什么没自动播」

**全屏**

- 全屏 / 铺满切换（转发 B 站自己的按钮，不伪造）
- 填充模式切换、全屏状态复位（黑屏自救）
- 可避让专注条，不被系统 UI 挡住内容

**内容治理**

- 分区屏蔽、UP 主屏蔽：软隐藏 + 单一 Observer + 异步 tid 查询，不重排页面
- `R` 键刷新推荐：点击后**验证卡片真的变了**才报成功，不假成功

**素材**

- 截帧：CORS 污染探针 + 系统分享优先
- 媒体直链：只读取「当前页面有权播放」的流，不破解、不去水印

## 安装

### Stay（iPad / iPhone 推荐）

1. App Store 安装 **Stay**，在 Safari 扩展里启用；
2. 用 Safari 打开下面这个直链，Stay 会接管：
   `https://raw.githubusercontent.com/ElioXBlaze/BilibiliPlus-Xi-Elio/main/BilibiliPlus-Xi-Elio.user.js`
3. 或者手动：Stay → 新建脚本 → 粘贴 `BilibiliPlus-Xi-Elio.user.js` 全文 → 保存。

### Tampermonkey / Userscripts 等

新建脚本，把 `BilibiliPlus-Xi-Elio.user.js` 全文粘进去保存即可。脚本会自动探测运行环境：

- `GM_*` 能用的就用 `GM_*`；
- Stay 上 `GM_*` 子集不全，自动降级到 `localStorage` 与原生 DOM / `fetch`。

## 使用

- 设置面板：菜单命令 **🎛 打开 BilibiliPlus Xi/Elio 设置**，或者在页面上用悬浮工具条；
- 共 21 条菜单命令，除设置外还包含搜索、倍速、弹幕、起播、音量、全屏、登录自检等诊断项，出问题时按提示复制诊断文本；
- 所有快捷键与按钮统一走一条命令总线，脚本内只有一处 `keydown` 捕获。

## 设计约束

脚本刻意守着几条线，方便你审阅：

- **单实例守卫**：同页面重复注入时只有一个实例生效；
- **单一 MutationObserver**：全站共用，SPA 导航感知，不叠监听；
- **UI 走 Shadow DOM**：不污染 B 站样式，也不被 B 站样式污染；
- **不劫持输入**：发弹幕仍走官方输入框，不抢 `A` / `Shift+Enter`；
- **不改写页面响应体**：避免干扰 B 站自己的 Vue 渲染；
- **不破解、不去水印**：直链仅限当前页面有权播放的流。

## 已知限制

- Stay 的公开资料未给出完整 `GM_*` 清单，因此个别能力（如 `GM_download`、`GM_xmlhttpRequest`）缺失时会降级为原生方案，行为可能略有差别；
- B 站前端改版后，个别选择器需要跟着更新，脚本里的诊断命令就是为了快速定位这类问题；
- 仅适配 iPad / iPhone 的 Safari 浏览器，桌面版未做验证。
