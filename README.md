> **本项目已停止维护，不再更新、不再修复、不再受理反馈。**
> 全部功能已迁移到新项目 **[Ibili](https://github.com/ElioXBlaze/Ibili)**，请改用那里。

## 请前往新项目

**Ibili** — https://github.com/ElioXBlaze/Ibili

安装直链：

```
https://raw.githubusercontent.com/ElioXBlaze/Ibili/main/Ibili.user.js
```

Ibili 保留了 BilibiliPlus 的全部能力，并在此基础上新增了三样：

- **整站页面美化** —— 首页、搜索、分区、动态、空间、收藏一起换新
- **九种界面语言** —— 简体中文 / 繁體中文（台灣）/ 繁體中文（香港）/ English / 日本語 / Русский / Español / Français (France) / Français (Canada)，首次启动先选语言
- **深色模式** —— 跟随系统或手动锁定

原有的自动起播、41 档倍速、触控手势、零导航搜索、一键三连、分区与 UP 主屏蔽、截帧、无水印直链、画中画，一项没少；键位和手势语义也保持不变，直接换装即可，不用重新学。

## 为什么停

两套脚本（页面美化与播放器增强）各自维护已经难以继续：它们都要接管 B 站首页的 DOM 与生命周期，分开发布只能靠"请只装一个"的说明来避免冲突，而用户真正想要的是一个能同时做好两件事的脚本。合并成 Ibili 之后，共用一份设置、一套菜单、一个生命周期，这才是可持续的形态。

## 原项目的最后版本

BilibiliPlus Xi/Elio 停在 **v2.5.1**（2026-11-22），代码仍在仓库里，历史 tag 与 Release 也都保留：

- `v2.5.1` — 网页端触控版（选中限制 / 控制台避右下角 / 设置居中）
- `v2.5.0` — 控制台可拖动吸附、后台小窗快捷键、设置页瘦身
- `v2.3.5` — 移动端同款触控手势
- `v2.0.5` — 移除「防跳转 / 去 App 横幅」
- `v2.0.2` — 首次开源

它做过的事，用一句话说：把网页版 B 站调成 iPad 该有的样子——保留网页端的全部能力（弹幕层、多档倍速、键盘、搜索、三连、下载），同时把移动端的触控手势做进 Safari 的网页层（长按倍速、上下滑调亮度与音量、松手锁定），而且全程不碰 `webkitEnterFullscreen()`，全屏只是转发 B 站自己的按钮。

这些能力现在都在 Ibili 里，并且做得更好。
