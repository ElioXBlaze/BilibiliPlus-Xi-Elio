# BilibiliPlus Xi/Elio · 哔哩哔哩 iPad 增强套件

> 当前版本：**2.5.1**　作者：Xi/Elio X. Blaze　完整图文教程见 [guide.html](guide.html)

**把网页版 B 站调成 iPad 该有的样子。**

网页端的 B 站功能全、键盘能打；移动端 App 的手势顺滑，但网页版一点都没有。这套脚本把两边叠在一起：**保留网页版的全部能力（弹幕层、多档倍速、键盘、搜索、三连、下载），同时把移动端那套触控手势做进 Safari 的网页层**——长按倍速、上下滑调亮度和音量、松手锁定，全都在网页里发生，不交给系统播放器。

据作者所知，这是目前第一款在 iOS / iPadOS 网页端实现播放器触控手势的 B 站增强脚本。这也是它最难的地方：系统全屏一旦接管，网页就收不到触摸；所以脚本从头到尾不碰 `webkitEnterFullscreen()`，全屏只是转发 B 站自己的按钮。

## 先解决四个老问题

| 你遇到的 | 以前 | 现在 |
|---|---|---|
| 发弹幕想用 `A` / `Shift+Enter`，结果按键被脚本抢走 | 脚本劫持了输入按键 | 整套发弹幕功能**彻底删除**，恢复 B 站官方输入框，脚本一个键都不拦 |
| 进播放页不自动播，每次手点，还要再点解除静音 | 默认不在网页端自动播 | 带声音优先起播 → 被拒才静音起播 → 首次手势里同步解除静音，音量自动记忆 |
| 按 `R` 提示「刷新成功」，推荐列表纹丝不动 | 只看点击是否成功 | 点真实按钮后**对比首屏 12 张卡片的 BV 号 / 标题**，真变了才报成功，没变就如实说 |
| 自动播放后暂停不住，要抽动两下才能暂停 | 脚本自己反复补播 | 自动起播只负责「刚点开、从未播放过」的那一次，`playing` 一触发就永久收手 |

## 八项能力（每项都能单独关掉）

1. **倍速 + 全屏真铺满** ✅ — 0.5×–5× 共 11 档，`［` `］` 步进并记住；`F` 转发 B 站自己的全屏按钮，脚本只给 `<video>` 加 inline 铺满，退出即还原。默认「智能」：横屏裁切去黑边、竖屏完整不裁人脸；`Shift+F` 换模式，`Shift+R` 一键复位。
2. **键盘快捷键** ✅ — `R` 刷新、`D` 弹幕开关、`S` 原生搜索、`Shift+S` 浮层搜索、`B` 三连、`C` 截帧、`F` 全屏、`G` 专注、`M` 静音；每条都能录键改绑。焦点从别的网页切回来自动夺回，输入法与输入框组合态自动让行。
3. **一键屏蔽 / 恢复分区** ✅ — `G` 一键学习模式：默认屏蔽动画/音乐/游戏/娱乐/影视/生活/美食/鬼畜，保留知识 36、科技 188、资讯 202、纪录片 177；子分区归并到一级分区不误伤，卡片没带分区就按 BV 号查一次 tid 并缓存。被屏蔽的卡片不留空白，原位显示「与学习无关」。
4. **一键屏蔽 / 恢复 UP 主** ✅ — 按 mid 精确匹配，昵称兜底；卡片右上角 ✕ 一键加入，设置页逐条恢复。软隐藏（加 class 不删节点），恢复瞬间生效，不破坏虚拟列表。
5. **下载无水印视频** ⚠️ 受限 — 只读当前页面已加载 / 当前账号有权请求的 playurl 原始流。合成 MP4 可直接下载；高清 DASH 是视频 + 音频两条 m4s，需要自行合并。原始流本身无水印，**UP 主烧进画面的水印去不掉、也不该去掉**。
6. **截帧** ✅ — `C` 截当前帧。先做 canvas 污染探针，跨域失败就明确提示「不允许导出」而不是给一张空白图；成功后优先走系统分享存进「文件」，也可长按预览图存相册。
7. **静音自动解决 + 音量记忆** ✅ — 只要调过音量就记住（含 0%），跨视频复用；解除静音在真实手势回调里同步执行。⚠️ iPad 上系统音量网页无权读写，脚本只控制静音开关。
8. **整合 + 这页教程** ✅ — 单文件脚本，内置 Shadow DOM 玻璃拟态设置面板（概览 / 功能开关 / 自检 / 更新日志四页，深色随系统，44px 触控目标），外加你正在看的这套图文教程。

## 触控手势：移动端的那套，搬进 Safari

| 手势 | 效果 |
|---|---|
| 长按画面 | 临时 2×，按住 10 秒锁定 |
| 长按中上滑 | 逐档升速（2× → 2.5× → 3× …），松手锁定当前档 |
| 长按中下滑再松手 | 唯一的「解锁 / 回原速」手势 |
| 左半屏上下滑 | 画面视觉亮度 |
| 右半屏上下滑 | 网页音量（接管 B 站对 volume 的写回，松手不回弹） |
| 水平滑动 | 让行给 B 站原生快进 / 拖进度 |

- 滑动时只有一条极简竖条 HUD + 百分比，3 秒自动消失；B 站自己的白底音量胶囊被屏蔽。
- 短按、没到阈值的微小抖动完全不拦：单击显隐工具栏、双击暂停、`click` / `dblclick` 全保留。
- 手势层只在播放器画面范围内生效，且**独占纵向**——横向滑动、系统滚动一律不动。

## 工具条与设置

- 右下 🎛 可拖动，松手吸附到就近边缘，位置会记住；展开后也能拖，永远躲开右下角 140px 见方（那是 iPadOS 窗口化拖角的位置）。
- 一级菜单每个按钮右侧直接显示当前热键，录键改绑后即时刷新。
- 设置面板居中，只分四页：⌂ 概览、⚙ 功能开关（所有设置与键位）、🩺 自检（诊断 / 登录 / 能力探测 / 冲突检测 / 日志导出）、🕘 更新日志。

## 安装

1. **装 Stay**：Stay → 脚本 → 新建 → 粘贴 `BilibiliPlus-Xi-Elio.user.js` 全文 → 保存并开启。元数据里的 `@inject-into content` 与 `GM_*` 权限已写好，Stay 缺哪个 API 会自行降级，不会白屏。
2. **把 B 站切到桌面版**：Safari 地址栏左侧「大小 / aA」→「请求桌面网站」，确认域名是 `www.bilibili.com`。本套件按桌面版 DOM 写，`m.bilibili.com` 只能用部分功能。
3. **刷新页面**：点右下 🎛 就是工具条；接上妙控键盘或外接键盘可直接开按。

也可以直接打开安装直链：

```
https://raw.githubusercontent.com/ElioXBlaze/BilibiliPlus-Xi-Elio/main/BilibiliPlus-Xi-Elio.user.js
```

## 必须说清楚的边界

- **「真铺满」的极限**：Safari 的地址栏、标签栏、底部手势条是系统外壳，任何网页脚本都隐藏不了。脚本的做法是转发 B 站自己的全屏按钮 + 给 `<video>` 加 inline 铺满样式，退出时按属性快照还原——不 fixed 容器、不改 body、不加黑底，所以结构上不会再出现「整页黑屏」。竖屏视频做不到「既完整又铺满」，二选一。
- **搜索零导航**：v1.3 起彻底不打开任何搜索页面，改调官方 WBI 搜索接口把结果画进浮层，点结果只打开 `www.bilibili.com/video/BV…` 同域链接。`Shift+R` 之外的旧缓存问题需手动清一次：设置 → Safari → 高级 → 网站数据 → 移除 bilibili.com。
- **系统音量网页无权**：iOS/iPadOS 上系统音量始终由物理键 / 控制中心控制，网页拿不到。左半屏那根竖条调的是画面视觉亮度与网页音量层。
- **自动小窗**：没有用户手势就想自动切 PiP，Apple 需要 video 走 `AVPlayerViewController`，网页层没有对应开关。v2.4.1 已把这类「静默接受」计为失败，不再谎报成功。
- **只为 iPad 网页版写**：桌面浏览器没做验证；`m.bilibili.com` 只能用到部分功能。
